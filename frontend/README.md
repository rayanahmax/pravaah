# PRAVAAH frontend

This folder is the Next.js application (App Router + TypeScript). It is the only deployable unit, so set a host's root directory to `frontend`.

The project overview, architecture, setup, environment variables and commands all live in the repository README: see [`../README.md`](../README.md).

Quick start from this folder:

```bash
npm install
cp .env.local.example .env.local   # fill in your Supabase values
npm run dev
```
